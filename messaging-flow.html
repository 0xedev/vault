3

Message is encrypted server-side with AES‑256‑GCM

Happens in src/lib/crypto.ts — per‑deal key derivation + random IV + authenticated encryption.

Server — encryptMessage()

// Key = scrypt(MASTER_SECRET, escrowId, 32) const key = scryptSync(process.env.MESSAGE_ENCRYPTION_KEY, escrowId, 32); // IV = crypto.randomBytes(12) — unique per message const iv = randomBytes(12); // AES-256-GCM: encrypt + authenticate const cipher = createCipheriv("aes-256-gcm", key, iv); const encrypted = cipher.update(plaintext, "utf8") + cipher.final(); const authTag = cipher.getAuthTag(); // 16‑byte GMAC // Store as: IV(12b) + authTag(16b) + ciphertext → base64 const combined = concat(iv, authTag, encrypted); return combined.toString("base64");

Key isolation: Each escrow gets a unique derived key via scrypt(MESSAGE_ENCRYPTION_KEY, escrowId).
Authenticated: GCM provides both confidentiality and integrity. Tampering is detected at decrypt time.
Random IV: Every message gets its own 96‑bit IV, so identical plaintexts produce different ciphertexts.

7

Decryption: the reverse of step 3

Happens server-side inside decryptMessage() — src/lib/crypto.ts:25

Server — decryptMessage()

// Re-derive the same key const key = scryptSync(process.env.MESSAGE_ENCRYPTION_KEY, escrowId, 32); // Split the combined blob const combined = Buffer.from(ciphertext, "base64"); const iv = combined.subarray(0, 12); // first 12 bytes const authTag = combined.subarray(12, 28); // next 16 bytes const encrypted = combined.subarray(28); // rest is ciphertext // AES-256-GCM decrypt + verify auth tag const decipher = createDecipheriv("aes-256-gcm", key, iv); decipher.setAuthTag(authTag); // will throw if tampered return decipher.update(encrypted) + decipher.final(); // Returns original plaintext — only if auth tag matches

What could go wrong

⚠ Tampered ciphertext — decipher.setAuthTag() will throw, caught by the try/catch in the route handler → displays "[encrypted message]"
⚠ Missing MESSAGE_ENCRYPTION_KEY — deriveKey() throws immediately, all message operations fail (by design)
ℹ Wrong escrowId — key derivation produces a different key, decryption fails with auth tag mismatch (GCM authenticated encryption detects this)
