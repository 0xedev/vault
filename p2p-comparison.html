Bottom line

Vault is architecturally more ambitious than Binance/Bybit P2P. Those platforms solved a simpler problem (crypto↔fiat with centralised custody) and polished the UX over years. Vault tackles a harder problem (illiquid digital assets with verifiable on-chain escrow) but is at MVP level on UX polish.

The encryption architecture is Vault's secret weapon. Binance/Bybit chats are plaintext — any support agent or database breach exposes every message ever sent. Vault's per-deal scrypt-derived AES-256-GCM means even with full DB access, messages are cryptographically unreadable without the MESSAGE_ENCRYPTION_KEY.

The main UX gap is real-time delivery. Binance/Bybit users expect instant message delivery. 5-second polling feels sluggish. This should be the #1 chat infrastructure priority.
